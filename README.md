# SpeedFast

Proyecto Evaluación 3 , Programación Orientada a Objetos.

## Actualización posterior a retroalimentación

Luego de realizar la entrega inicial, recibí retroalimentación correspondiente a la actividad formativa anterior.

A partir de dicha retroalimentación se realizaron las siguientes mejoras:

- Se ajustó el cálculo de tiempo de entrega en `PedidoEncomienda` utilizando `Math.round()` para evitar el truncamiento directo de valores decimales.
- Se mejoró el uso de polimorfismo en `Main` utilizando un arreglo de tipo `Pedido` para reducir llamadas repetitivas.

Estas modificaciones fueron realizadas antes de la fecha límite de la evaluación.

La versión entregada previamente en el AVA corresponde al estado anterior a estas mejoras, ya que la plataforma no permite reemplazar el archivo una vez enviado.
